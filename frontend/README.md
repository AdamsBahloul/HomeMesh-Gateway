# SmartBridge OS - Web Console Dashboard

The **SmartBridge OS Dashboard** is a high-performance single page web application built with React 18, TypeScript, Vite, and Tailwind CSS.

## Features

- **Industrial Dark-Mode Aesthetic**: Custom glassmorphism components with live status badges.
- **Real-Time Telemetry & Gauges**: Dynamic WebSocket subscriber for instantaneous sensor updates.
- **Node Management & Remote Actuation**: Direct toggle control over relay actuators.
- **OTA Firmware Drag & Drop**: Drag-and-drop file uploader with automated versioning.

## Local Execution

```bash
npm install
npm run dev
```
Accessible locally at `http://localhost:3000`.
